# 熊本ボランティア速報板

令和8年熊本地震のボランティア活動前チェック用・非公式ポータルサイト。
「どこへ行くか」「募集しているか」「当日どう動くか」を1ページに集約しています。

## 自動更新される部分／されない部分

**自動更新される（＝編集不要）**

| セクション | 仕組み |
|---|---|
| ②各市町ボランティアセンター設置一覧（募集状況） | 熊本県社協の公式Kintoneビューをiframe埋め込み |
| ④断水・給水・仮設トイレ・災害ごみ仮置場 | くまもと被災者支援ナビ「支援場所マップ」をiframe埋め込み（`support-map?types=water,well,toilet,gomi`） |
| ⑦宿泊（楽天トラベル・じゃらん） | 検索結果ページへのリンクなので常に最新の空室 |
| ⑥コンビニの店舗検索リンク | 各社の公式店舗検索へのリンク |
| ⑧現地の声（X検索・Instagram） | 検索ウィジェット／検索ページへのリンク |

**自動更新されない（＝状況が変わったら手動で編集）**

| 要素 | 編集箇所 |
|---|---|
| 地図のVCピン（場所・ラベル） | `index.html` 内 `vcData` 配列。VCの新設・移転・廃止時のみ |
| 地図の震源地★ | `index.html` 内 `epicenter`。固定データのため**更新不要** |
| ③当日の流れ | HTMLの `#flow` セクション |
| ⑤高速道路無料措置の手順 | HTMLの `#highway` セクション（リンク先PDFは先方が更新） |
| ⑥コンビニの休業店舗数 | HTMLの `#convenience` セクション。2026年8月上旬の報道値 |
| **お盆限定ブロック（②の直前）** | `index.html` 内 `<!-- ▼▼▼ お盆限定ブロック -->` 〜 `<!-- ▲▲▲ -->` と、CSSの `.obon-*` 一式。**2026年8月17日に削除**（下記参照） |
| 現地レポート（`.report-box`） | ③に2か所・⑤に1か所。**2026年8月12日時点**の現地確認情報 |

**現地レポートの扱い：** `.report-box` は現地で確認した体験ベースの情報で、自動更新されません。必ず `.report-date`（「現地で確認｜YYYY年M月D日時点」）とセットで書き、内容を更新したら日付も必ず更新してください。特に道路状況は復旧工事や新たな規制で変わるため、日付のない状態で残さないこと。

**設計方針：** 募集中かどうかのステータスは地図ピンに持たせていません。手入力だとすぐ古くなるためです。募集状況は必ず②の自動更新される公式一覧表で確認する設計にしています。

**お盆限定ブロックの扱い（期間限定の例外）：** 上の設計方針の唯一の例外として、②の直前に「お盆期間の活動状況」ブロックを臨時で置いています。お盆期間は休止するセンターがあり、②の一覧表だけでは休止がわからないためです。県社協が2026年8月12日に発表した内容（活動中4／休止7）と、同日午後6時時点で予約受付中だったセンター（美里町・益城町）の予約フォームを手入力で載せています。

**このブロックは2026年8月17日に削除してください。** 削除するのは次の2か所です。

1. `index.html` の `<!-- ▼▼▼ お盆限定ブロック -->` から `<!-- ▲▲▲ お盆限定ブロック ここまで -->` まで
2. 同ファイルのCSS `/* ▼▼▼ お盆限定ブロック用スタイル */` から `/* ▲▲▲ ... ここまで */` まで

削除すれば、募集状況は②の自動更新される公式表のみ、という元の設計に戻ります。ナビゲーション（①〜⑧）はこのブロックのために変更していないので、削除時に触る必要はありません。

iframeが表示されない場合（埋め込み元がブロックした場合）は、各ブロック直下のフォールバックリンクが機能します。

## VCピンを追加・修正する場合

`index.html` 内の `vcData` 配列を編集：

```js
{ name: "○○市災害ボランティアセンター", area: "○○市", lat: 00.000000, lng: 000.000000,
  place: "開設場所の住所",
  tel: "000-0000-0000",
  source: "https://...", sourceLabel: "○○市社協公式ページ" }
```

- `area` が地図上に常時表示されるラベルです（一覧表の「市町村名」列と一致させてください）
- 座標はGoogleマップで住所検索 → 右クリック「この場所について」で取得できます
- 募集ステータスの項目は意図的にありません

現在のピン（11か所）：熊本市／八代市／宇土市／宇城市／美里町／御船町／嘉島町／益城町／甲佐町／氷川町／芦北町

## 震源地★について

`index.html` 内の `epicenter` で定義しています。**固定データなので更新は不要です。**

- 発生：2026年7月28日 16時27分頃
- 規模・深さ・震度：**気象庁**発表（M7.1／深さ16km／最大震度7＝宇城市・氷川町）
- 緯度経度：**USGS**発表（32.6817N / 130.7217E）
  - 気象庁は緯度経度を公表資料で明示していないため、座標のみUSGSを採用しています
  - USGSの規模・深さの推定値（Mw6.8／10km）は気象庁と異なるため、ポップアップに併記しています
- 日奈久断層帯の活動による地震である可能性が高いとされています（日本活断層学会）

## 断水情報について（手動更新は不要）

かつて地図上に手動メンテの断水エリア円（`waterData`）を描いていましたが、自動更新されず古くなるため**廃止しました**。
断水・給水・仮設トイレ・災害ごみ仮置場は、④セクションのくまもと被災者支援ナビ「支援場所マップ」の埋め込みに一本化しています。

表示する種類を変えたい場合は、iframeの `types` パラメータを編集してください。

```
https://kumamoto-shien.jp/support-map?types=water,well,toilet,gomi
```

指定可能な種類：`water`（給水）／`well`（協力井戸）／`toilet`（災害用トイレ）／`gomi`（災害ごみ仮置場）ほか、お風呂・炊き出しなど。iframeの `src` と直下の `.fallback-link` の `href` を**両方**同じURLに揃えてください。

### 更新のしかた

`index.html` を編集して、このフォルダで以下を実行すると1〜2分で本番に反映されます。

```bash

git commit -m "VC情報を更新"
git push
```
